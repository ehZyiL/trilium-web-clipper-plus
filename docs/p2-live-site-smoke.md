# P2 真实站点 Smoke 验证

验证日期：2026-10-27。

执行命令：

```text
npm run smoke:sites
```

该命令只读取公开页面，不提交表单、不登录、不写入第三方站点。

| 站点 | 页面类型 | HTTP | 实际 reader | 结果 |
| --- | --- | ---: | --- | --- |
| 掘金 | 公开文章 | 200 | `juejin` | 正文 2009 字符，脚本和危险 URL 已清除 |
| 少数派 | 公开文章 | 200 | `sspai` | 正文 4149 字符，文章容器命中 |
| GitHub | 公开仓库 README | 200 | `github` | README 21855 字符，代码块保留 |
| V2EX | 公开主题 | 200 | `v2ex` | 正文 1538 字符 |
| YouTube | 视频页 | 200 | `youtube` | 标题和描述正文已提取 |
| Bilibili | 视频页 | 200 | `bilibili` | 标题和描述正文已提取 |

以下页面也做过读取探测，但不能把结果当成正文 reader 的回归证据：知乎返回 403，BOSS 详情页返回安全验证；微信、即刻、小宇宙、雪球和社交网站首页没有具体文章/帖子正文；Hacker News 的测试地址返回 419。对应站点仍由 DOM fixture 覆盖测试验证，遇到登录、风控或动态渲染时会回退到 Readability/候选正文策略。

YouTube 和 Bilibili 当前只接入网页标题与描述的 HTML 剪藏，不包含参考项目中的字幕抓取和时间轴生成。
